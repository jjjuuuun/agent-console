# Changelog: @agent-console/ui

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). A change that breaks the version
range of an internal dependency bumps the other package's version and is recorded here.

## [Unreleased]
- 0.2.1 (11/27): added the icon `plug` (a connection, with the lower right corner left empty). `CommandItem` gained the optional field `keywords` (aliases used only for search), and `filterCommandGroups` also looks at them. `ToastInput.text` and `action.label` accept a `ReactNode` (plain text still works; with an element that re-renders for the language, the text of a toast that is still showing changes when the language switches). `FileTree` gained the optional prop `locale` (the language for name sorting, default `en`) and the fourth argument of `buildRows`. Existing behavior is the same.
- Measurement-based collapsing: even when the container is 640px or wider, `PageHeader` collapses the secondary actions into the `more` menu when they would make the title narrower than 120px (`data-collapsed`, `ResizeObserver`). For languages with longer text (English). No public API change.
- Messages (0.2.0): moved the component default messages ("More", "N more", the duplicate shortcut warning and the outside-provider error) to `src/locales/ko.json` (`defaultUiMessages` is still ko) and added `en.json`. Subpath exports `./locales/ko` and `./locales/en`, the optional prop `messages` on `ChipRow`, `Tabs`, `PageHeader` and `ShortcutProvider`, and the public `UiMessages`, `defaultUiMessages` and `formatUiMessage`. Added tests for matching keys and placeholders and for no Korean string literals in the source. The default behavior is the same.
- 0.1.1 (11/26): `.ac-pageheader-status` is now flex with a `--ac-space-2` gap, so the Tag and the text in the status cell no longer touch.
- Removed the public API `getResolvedTokens` (for the xterm theme; nothing used it after the web terminal was removed). Removed 18 unused tokens: `--ac-lh-lg`, `--ac-chevron`, `--ac-edge-route-pad`, `--ac-edge-selected-width`, `--ac-radius-xl`, `--ac-topbar-h`, `--ac-issues-h`, `--ac-dock-h`, `--ac-z-dock`, `--ac-z-canvas`, `--ac-log-row-h-compact`, `--ac-log-detail-w`, `--ac-lane-label-w`, `--ac-dash-row-h`, `--ac-dash-gap`, `--ac-trace-label-w`, `--ac-space-0` and `--ac-card-pad`. `.ac-toasts` uses `bottom: var(--ac-space-4)` without the dock height.
- `Dialog` as a three-row grid (title, scrolling body, fixed bottom `actions`), `size` sm|md|lg|xl (`wide` is a deprecated alias of lg), a reset for `fieldset` in the body, and `.ac-choice`. `Tabs` overflow into "More ▾" (`moreLabel`) and `TabItem.title`. New `ChipRow` (a +N popover), `ActionButton` and `ActionDef`, `Tooltip` (CSS, 400ms), `Popover` and `Menu`, `PageHeader` `secondaryActions` (container query at 640px) and `moreLabel`, and `computeVisible` and `useOverflowFit`. 21 new icons (refresh close more plus undo check trash send stop panel-left-close/open filter columns table chevron-right/left/down expand play pencil pin). Tokens `--ac-chip-max-w`, `--ac-tab-min/max-w`, `--ac-dialog-w-*`, `--ac-dialog-max-h`, `--ac-header-title-max` and `--ac-tip-delay`. No new external dependencies.
- Tokens for standalone delegation, loops, conditions and nested teams: `--ac-edge-loop`, `--ac-edge-failure`, `--ac-loop-region(-offset)`, `--ac-edge-pattern-0..3`, `--ac-edge-chip-max-w`, `--ac-stack-offset`, `--ac-run-badge-h`, `--ac-run-badge-picked`, `--ac-run-list-row-h` and `--ac-progress-indent`. No new hex values (aliases).
- Public `useModalBackdrop`, `trapTabKey` and `FOCUSABLE_SELECTOR` (removes the duplicate in the app Drawer). When focus returns and the trigger is gone, focus is not placed anywhere.
- New `MiddleEllipsis` and `middleEllipsis` (middle ellipsis for ids and hashes, keeping the first 8 and last 4 characters, with a full-text tooltip and an optional copy button; `.ac-middle-ellipsis`). No new external dependencies.
