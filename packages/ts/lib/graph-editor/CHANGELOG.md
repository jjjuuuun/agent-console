# 변경 기록: @agent-console/graph-editor

형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따른다. 사내 의존 범위를 깨는 변경은 상대 패키지 버전을 올리고 여기에 적는다.

## [미출시]
- 노드 어디서나 연결(5.2R.24, UX-P11): 선택한 노드의 가장자리 띠(핸들 id `edge:<면>`, 줌에 맞춰 굵기 보정)에서 끌어 상대 노드 **몸체 어디에 놓아도** 연결한다. 포트는 순수 함수 `resolveEnds`·`inferKindPorts`(`logic/inferPorts.ts`)가 시작/끝 핸들이 정한 포트 -> 종류 `default_ports` -> 노드 포트 목록의 첫 호환 포트 순으로 정하고(노드 타입·종류·포트 이름은 비교하지 않는다), 후보 종류가 둘 이상이면 `EdgeKindDialog`에 포트 열(`EdgeKindCandidateInfo.portsText`)을 더해 한 번에 고른다. 포트 핸들에서 시작해 몸체에 놓아도 된다(시작 핸들 방향이 출발/도착을 정한다). 추론으로 만든 연결은 토스트(되돌리기)로 어느 포트에 붙었는지 알린다. 핸들 스냅 반경을 20 -> 8px로 줄였다(`CONNECTION_RADIUS`). 메시지 `edgeKindPorts`·`connectedInferred`·`dropHere`, `NodeCardProps.edgeBands`. 키보드 대안(포트 핸들 연결·`T` 키)은 그대로.
- 팀 편집기 레이아웃(5.2R.20): `canvasActions` 슬롯, 미니맵 토글(`onShowMinimapChange`, 기본 크기 140x96), 오버레이 팔레트(`paletteOverlay`·`paletteOpen`·`onPaletteClose`), `GraphEditorHandle.addNodeAtCenter`, 순수 함수 `centerFreePosition`, 메시지 `minimapShow`·`minimapHide`. 하단 보기 도구줄은 한 줄 유지(`nowrap`). 새 props를 안 주면 렌더 결과는 그대로(기본 미니맵 크기만 작아짐).
- 연결선 기본 자동 경로(5.2R.23): 모양 결정 6순위 내장이 `auto`(레지스트리에 없으면 `bezier`; `layout.shape` 없이 `waypoints`·`bend`·`radius`·`label_*`가 있는 직접 고친 선은 이전 기본 `bezier`로 읽음, `hasManualRoute`·`builtinEdgeShape`·`DEFAULT_EDGE_SHAPE`). 같은 줄에서 겹치는 평행 선분 6px 벌리기(`nudgeParallel`, `RouteOptions.nudge`). `createAutoPath`/`DEFAULT_AUTO_PATH_OPTIONS`로 `autoPath` 탐색 상한을 옵션화. 사후 안내를 경고 칩 "연결선 N개가 노드를 지납니다 · [자동 경로로]"로 교체(`EdgeTroubleChip`의 props가 `count`·`onAutoRoute`로 바뀜, 메시지 `troubleOpen` → `troubleAutoRoute`, `troubleHint`는 `{count}` 자리 표시). 정리 엔진 없이도 뜬다. `newGraphUi()`(새 그래프 노드 방향 `auto`).
- 독립 위임·반복·조건·중첩 팀(5R.16): `resolveEdgeStyle`·`loopRegion`·`closesFlowLoop`·`planConnection` 순수 함수, 속성 기반 연결선 스타일(색·패턴·아이콘·기본 모양 `auto`), 연결 칩 확장(`edgeExtraChips`·`edgeBadges`·`renderIcon`, 4개 + `+N`, 줌 LOD), 반복 영역 강조, 순환을 닫는 연결 만들기(비활성 행·기본 선택 `EdgeKindDialog.info`), `bindSummaries`(정의 바인딩 카드·[열기]·`Alt+Enter`), `ui_hints.shape: stacked`, `nodeRunBadges`, 팔레트 `DefinitionItem.meta`·`disabledReason`, ELK 되돌아가는 연결 처리(`LayoutEdgeInput.back`·`ElkEngineOptions.cycleBreaking`), 팔레트로 추가한 새 노드 화면 이동. `checkConnection`은 `cycle` 종류의 순환을 허용. `ChipView`에 선택 필드(`fullTitle`·`iconName`·`tone`·`dashed`) 추가. 새 props를 안 주면 렌더 결과는 그대로.
- 연결선 P2 후속(4R.20): `MultiLayoutPanel`(다중 선택 일괄 [모양 ▾]·[경로 초기화] 확인 단계·[방향])와 `ConfigPanelContext.multiLayout`·`LayoutPanels.multi`, `EdgeContextMenu`(연결선 우클릭 + `Shift+F10`/ContextMenu 키), 노드 방향 `auto`(`AUTO_DIRECTION`·`isAutoDirection`, 파생·저장 안 함), 같은 면 핸들을 상대 노드 위치 순으로 정렬(`orderByPeer`·`placeHandles`의 `peerOf`), 자동 경로 장애물에 실제 렌더 카드 크기 사용(`actualNodeSize`), `LayoutEngineDescriptor.edgeShapeOption`("연결선도 자동 경로로", `createElkEngine`은 기본 `auto`). `patchEdgesLayout`·`patchNodesLayout`·`countResettableEdges` 공개. 메시지 키 추가(`multiLayoutMixed`·`edgeMenu*`·`tidyAutoRoutes`·`nodeLayoutAutoDirectionHint`·`directionLabels.auto`). layout이 없는 그래프의 렌더는 그대로.
- 정리·자동 배치(3R.26): `layoutEngines` props, `LayoutEngineDescriptor`/`OptionDecl`, `createElkEngine`(elkjs ~0.12.0 동적 import + Worker, ELK 타입 격리), `TidyPopover`([정리 ▾]·`L`, 미리보기·적용 1회 `onChange` reason `auto-layout`·취소·10초 제한·실패 재시도·모든 연결선 경로 초기화), `detectEdgeTrouble`와 `EdgeTroubleChip`, `storage`/`storageKeyPrefix`/`troubleHint` props. 레이아웃 되돌리기 스택이 `Graph.ui.layout`을 비교·복원한다(그 밖의 `ui` 키는 현재 값 유지).
- 노드 배치(3R.23): `NodeLayoutPanel`([배치] 탭), `R`(방향 순환)·툴바 [방향 바꾸기], 핸들 롱프레스 400ms/`Alt`+드래그로 포트 면 이동, `Ctrl+Z`/`Ctrl+Shift+Z` 레이아웃 되돌리기 30단계(`LayoutHistory`), `ChangeReason`에 `auto-layout` 추가, 노드를 함께 옮기면 사이 엣지의 경유점도 이동(`moveNodesWithWaypoints`), `onLayoutPanelsChange`·`ConfigPanelContext.nodeLayout`, `patchGraphUiLayout`(`Graph.ui` 병합). `GraphEditorHandle`·기존 props는 그대로.
- 연결선 편집(3R.22): `EdgeLayoutPanel`(연결 패널 "모양·경로"), `EdgeWaypointLayer`(경유점 만들기·이동·삭제·일직선 자동 정리·줌 보정), 라벨 칩 드래그, `S`/`X`/`Enter` 키와 경로 편집 모드(aria-live). `ChangeReason`에 `layout` 추가, `ConfigPanelContext.edgeLayout`, `inheritedEdgeShape`, `logic/edgeLayoutOps.ts` 순수 함수 공개. 엣지 접근성 이름에 모양·경유점 덧붙임(값이 있을 때만).
- 연결선: `AcEdge`가 결정된 모양(`edgeShapes`·`layoutDefaults` props)과 라벨 위치(`label_t`·`label_offset`)로 그린다. layout이 없으면 이전과 같은 경로.
- 포트 면: 포트별 `Position`, 위·아래 면 균등 배치, 면 글리프·라벨 칩, 핸들 위치가 바뀌면 `useUpdateNodeInternals`.
- 라벨의 추가 문구는 선언형 칩(`value_pointer`·`placement: "title"`)만. 엣지 `config.label` 직접 읽기를 없앴다.
